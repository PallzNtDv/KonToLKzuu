Personal repository to build customized kernel drivers and KernelSU managers for POCO M3 Pro 5G / Redmi Note 10 5G (codename: `camellia` / `camellian`).

Fully automated CI/CD pipeline built on top of GitHub Actions for 4.14 Non-GKI Android kernels.

## Features
- **KernelSU Multi-Fork Support**: Official KernelSU, xxKSU, and SUKISU.
- **Kernel Enhancements**: Integrated SUSFS 4.14 & Baseband-Guard (BBG) support.
- **Toolchain Options**: Proton-Clang and Official AOSP Clang.
- **Userspace Compilation**: Automatic Rust `lpud` binary cross-compilation for xxKSU/SUKISU.
- **Direct Releases**: Automated deployment of AnyKernel3 zips, Manager APKs, and standalone binaries straight to GitHub Releases.
